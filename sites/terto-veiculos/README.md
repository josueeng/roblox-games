# Terto Veículos — site

Demonstração de site da Mandacodex (Josué Lopes) para a Terto Veículos, Petrolina-PE.

- `terto-veiculos.html` — site em um arquivo só (fotos embutidas). Abre direto no navegador.
- `site/` — o mesmo site com as fotos separadas (`index.html` + `img/`), para publicar.
- `Proposta-Mandacodex-Terto.pdf` — proposta para o cliente (R$ 250/ano, atualização de estoque fora do plano). Fonte em `proposta/proposta.html`.

Os botões "Fale conosco" apontam para linktr.ee/tertoveiculospnz, porque o número de WhatsApp não aparece no perfil.
Antes de publicar, confirmar com o cliente o WhatsApp, os modelos do estoque, o horário e as condições de pagamento.
