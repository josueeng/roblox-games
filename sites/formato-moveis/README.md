# Formato Móveis em Madeira — site e proposta

Projeto da Mandacodex (Josué Lopes) para a Formato Móveis em Madeira, Petrolina-PE.

- `formato-moveis.html` — site em um arquivo só (fotos embutidas). Abre direto no navegador.
- `site/` — o mesmo site com as fotos separadas (`index.html` + `img/`), para publicar (ex.: arrastar a pasta no Netlify Drop).
- `Proposta-Mandacodex-Formato.pdf` — proposta para o cliente (R$ 250/ano). Fonte em `proposta/proposta.html`.
- `figma/pranchas/` — pranchas em SVG para importar no Figma. `figma/board.py` gera as pranchas.

Antes de publicar, confirmar com o cliente o horário de todos os dias e o número do WhatsApp.
