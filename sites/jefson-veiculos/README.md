# Jefson Veículos — site

Demonstração de site da Mandacodex (Josué Lopes) para a Jefson Veículos, Petrolina-PE.

- `jefson-veiculos.html` — site em um arquivo só (fotos embutidas). Abre direto no navegador.
- `site/` — o mesmo site com as fotos separadas (`index.html` + `img/`), para publicar.
- `Proposta-Mandacodex-Jefson.pdf` — proposta para o cliente (R$ 250/ano). Fonte em `proposta/proposta.html`.

As fotos foram recortadas do Instagram da loja. Antes de publicar, confirmar com o cliente os modelos do estoque, o horário de funcionamento e as formas de pagamento.
